# Tipografia da interface

IBM Plex Sans, pesos Regular (400), Medium (500) e SemiBold (600), subconjunto Latin1 em WOFF2. Os três arquivos somam aproximadamente 65 KB e atendem ao português usado na interface. A fonte é servida localmente, inclusive quando o jogo abre por file://. Menu e HUD compartilham esses arquivos locais.

Arquivos originais, sem modificação, obtidos do [repositório oficial IBM/plex](https://github.com/IBM/plex/tree/master/packages/plex-sans/fonts/split/woff2). Licença SIL Open Font License 1.1 em **OFL.txt**, copiada do mesmo repositório.
